# Land Record Management System

## Project Overview
The Land Record Management System is a simple web-based application designed to manage land ownership records digitally. It allows users to add, view, search, and delete land records.

## Features
- Add new land records.
- Store owner names and land IDs.
- Record land area and location.
- Search records by owner name or land ID.
- Delete existing records.
- Simple and user-friendly interface.

## Technologies Used
- HTML5
- CSS3
- JavaScript

## How to Run
1. Clone or download the repository.
2. Open the project folder in VS Code.
3. Open `index.html` in a browser.
4. Use the application to manage land records.
